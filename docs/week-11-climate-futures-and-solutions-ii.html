11 Week 11: Climate Futures and Solutions (II)

In this exercise you will run a simple global climate model called Hector. Hector is the default carbon cycle module for the integrated assessment model GCAM (Global Change Assessment Model). The section below will show you how to run Hector.

  • Load libraries
library(hector)
library(hectordata)

11.1 Exercise (1)

  • Run the model To run Hector you need to initialize a Hector core. The core is a self-contained object that contains information about all of Hector’s inputs and outputs:
# Initialize hector core
ini_file <- system.file("input/hector_ssp585.ini", package = "hector")
core <- newcore(ini_file)

# Run the model
run(core)

## Current date:    2300

results_default <- fetchvars(core, 1950:2300)

# Set up a layout for multiple plots
par(mfrow = c(2,2), mar = c(4,4,1,1))

for (i in 1:length(categories)) {
  
  # Subset data frame 
  data <- df[df$variable == categories[i], ]
  unit <- unique(data$units)
  # Plot data
  plot(x = data$year, y = data$value, ylab = paste(categories[i], unit), xlab = "Year", type = "l")
}

11.2 Exercise (2)

The model accounts for the CO2 fertilization effect using a multiplier \(f\):

\[ f = 1 + \beta_i \left( \log \left( \frac{C_{atm}}{C0}\right) \right) \]

  • Let’s increase the parameter \(\beta_i\) from its default value of 0.53 to 0.8 and run the model again
ini_file <- system.file("input/hector_ssp585.ini", package = "hector")

core <- newcore(ini_file)

# Run the model
run(core)
## Hector core: Unnamed Hector core
## Start date:  1745
## End date:    2300
## Current date:    2300
## Input file:  /global/home/hpc5112/ENSC430/Rlib/hector/input/hector_ssp585.ini
# Obtain the results
results_default <- fetchvars(core, 1950:2300)

# The current value for beta is
beta <- fetchvars(core, NA, BETA())

# Let's increase this to 0.8
setvar(core, NA, BETA(), 0.8, "(unitless)")

# Reset the core with the new value
reset(core)
## Hector core: Unnamed Hector core
## Start date:  1745
## End date:    2300
## Current date:    1745
## Input file:  /global/home/hpc5112/ENSC430/Rlib/hector/input/hector_ssp585.ini
# run the model
run(core)
## Hector core: Unnamed Hector core
## Start date:  1745
## End date:    2300
## Current date:    2300
## Input file:  /global/home/hpc5112/ENSC430/Rlib/hector/input/hector_ssp585.ini
# Get the results
results_beta <- fetchvars(core, 1950:2300)

# Show the impact by plotting the results from the default run and from the new run.

df01 <- results_default
df02 <- results_beta

categories <- unique(df01$variable)

# Set up a layout for multiple plots
par(mfrow = c(2,2), mar = c(4,4,1,1))

# Loop through each category and create a plot for each category
for (i in 1:length(categories)) {
  
  # Subset data frame 
  data <- df01[df01$variable == categories[i], ]
  unit <- unique(data$units)
  # Plot data
  plot(x = data$year, y = data$value, ylab = paste(categories[i], unit), xlab = "Year", type = "l")
  
  data <- df02[df02$variable == categories[i], ]
  lines(x = data$year, y = data$value, type = "l", col = "red")
  abline(v = 2100)
  legend("bottomright", c("beta = 0.53", "beta = 0.8"), col = c("black", "red"), pch = 16, bty = "n")
}
  • How does the increase in \(\beta_i\) affect the atmospheric CO2 concentration, radiative forcing, and global mean surface temperature?
