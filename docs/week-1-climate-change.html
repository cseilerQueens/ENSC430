1 Week 1: Climate Change

1.1 Motivation

Why are we learning R? Throughout this course, you will use environmental and climate datasets to investigate questions about how the Earth system is changing. R is the programming language we will use to access, process, analyze, and visualize these data. You do not need to become a professional programmer. Instead, the goal is to become sufficiently comfortable with R that you can use it as a scientific tool and understand what your analysis is doing.

1.3 RStudio

We will use RStudio to work with R. RStudio provides several areas that you will use throughout the course:

  • Source: Where you write and save your R code and R Markdown documents.
  • Console: Where R executes your code and displays the results.
  • Environment: Where you can see the objects that you have created in R.
  • Files: Where you can access the files in your current project.
  • Plots: Where R displays figures that you create.

To write your first R command, enter the following in the console:

x <- 3

Now look at the Environment pane. You should see an object called x with a value of 3. The symbol <- assigns a value to an object. In this case, we have created an object called x and assigned it the value 3. Throughout this course, you will generally write your code in the Source pane and run it in the Console. This allows you to save your analysis and reproduce it later.

1.4 R Markdown

You will complete the tutorials using R Markdown. R Markdown allows you to combine text, R code, and figures in a single document. This makes it possible to document your analysis and produce a complete report from the same file. R Markdown uses simple formatting rules. For example, one hash symbol (#) creates a large heading. Two hash symbols (##) creates a smaller heading. An asterisk (*) creates a bullet point. R code is placed inside code chunks. A code chunk begins with three backticks followed by the letter r enclosed in curly brackets and ends with three backticks. Add the following code chunk to your R Markdown document and run it:

x <- 4

You can run the code line-by-line by putting the cursor in the first line and then hit Ctrl Enter. The instructions appear in the console at the bottom. This technique is very helpful for trying to understand what the code is doing. Another way to run the code is by clicking on the icons on the top-right of each code chunk. Click on the those items to see what they do.

1.7 Data frames

So far, year and GMST are separate vectors. It is often more convenient to combine related variables into a data frame, which is essentially a table of data. Let’s combine the two vectors:

data <- data.frame(year, GMST)

We can now explore the content of the data frame:

head(data)
str(data)
summary(data)
names(data)

You can access an individual column using the $ symbol:

data$GMST

For example, we can calculate the mean directly from the data frame:

mean(data$GMST)

1.8 Selecting data

One of the most important tasks when working with environmental data is selecting the observations that are relevant to a particular question. For example, let’s get all years with a global mean surface temperature exceeding 15 degrees Celsius:

data[data$GMST > 15, ]

We can combine two conditions using &. For example, the following selects years when GMST was between 14.0 and 14.5 degrees Celsius:

data[data$GMST >= 14 & data$GMST <= 14.5, ]

Let us now find which years were the four hottest years on record. To do this, we first sort the data frame by temperature using the order() function and get the 4 hottest years.

data_sorted <- data[order(data$GMST, decreasing = TRUE), ]
data_sorted[1:4,]

1.9 Comparing time periods

We can use the same approach to investigate changes between different periods. For example, the following selects observations from 1850 to 1900:

early <- data[data$year >= 1850 & data$year <= 1900, ]

We can then calculate the average GMST during this period:

1.10 El Nino

El Nino events are associated with substantial changes in the climate system on a global scale. Let us mark the years that qualify as El Nino years. The following vector contains the El Nino years used for this exercise:

El_Nino <- c(
  1897, 1900, 1903, 1906, 1915, 1919, 1926, 1931, 1941,
  1942, 1958, 1966, 1973, 1978, 1980, 1983, 1987, 1988,
  1992, 1995, 1998, 2003, 2007, 2010, 2016
)

We can determine whether each year in our GMST dataset is an El Nino year using %in%:

data$El_Nino <- data$year %in% El_Nino
head(data)

The new El_Nino column contains TRUE for El Nino years and FALSE for all other years. We can now select the El Nino years and non-El Nino years:

EN.yes <- data[data$El_Nino == TRUE, ]
EN.no <- data[data$El_Nino == FALSE, ]

1.11 Plotting

We can visualize the GMST data using a simple line plot:

plot(x = data$year, y = data$GMST, type = "l", xlab = "Year", ylab = "GMST (Degrees Celsius)")
grid()

The type = "l" argument tells R to connect the observations with lines. We can also add the El Niño years to the plot:

plot(x = data$year, y = data$GMST, type = "l", xlab = "Year", ylab = "GMST (Degrees Celsius)")
grid()
EN <- data[data$El_Nino == TRUE,]
points(EN$year, EN$GMST, pch = 16, col = "red")

Modify the x and y axis using xlim and ylim:

plot(x = data$year, y = data$GMST, type = "l", xlab = "Year", ylab = "GMST (Degrees Celsius)", 
     xlim = c(1980, 2015), ylim = c(14, 15))
grid()
EN <- data[data$El_Nino == TRUE,]
points(EN$year, EN$GMST, pch = 16, col = "red")

1.12 Quantifying the warming trend

The plot shows that global mean surface temperature has increased substantially since 1850. We can use a simple linear model to quantify this trend. The following code fits a linear relationship between GMST and year:

model <- lm(GMST ~ year, data = data)
summary(model)

The coefficient associated with year represents the estimated change in GMST per year. We can extract the model coefficients using:

coef(model)

The second coefficient is the estimated change in GMST per year. We can multiply it by 100 to express the trend as degrees Celsius per century.

coef(model)[2] * 100

Quiz Question: What is the estimated rate of global warming in degrees Celsius per century over the entire 1850–2024 period?

1.13 Has the rate of warming changed?

A single trend over 175 years assumes that the rate of warming is constant. We can investigate whether this assumption is reasonable by calculating trends for different periods. First, create a dataset containing observations from 1850 to 1950 only

early <- data[data$year >= 1850 & data$year <= 1950, ]
early_model <- lm(GMST ~ year, data = early)
early_trend <- coef(early_model)[2] * 100
print(early_trend)
