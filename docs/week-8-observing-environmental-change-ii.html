8 Week 8: Observing Environmental Change (II)

In this tutorial, you will explore how precipitation (PR), near-surface temperature (TAS), and incoming solar radiation (RSDS) influence anomalies in the enhanced vegetation index (EVI). You’ll learn how to process the data to combine reanalysis data (PR, TAS, RSDS) with satellite data (EVI). The analysis is divided into two parts: first, you’ll conduct a Granger analysis, which you’re already familiar with, and second, you’ll perform a cross-correlation analysis to examine how correlations between variables shift with varying time lags. By the end of the tutorial, you’ll produce two maps: one showing the time lags at which correlations between meteorological variables and EVI are strongest, and another displaying the corresponding correlation coefficients. This information will allow you to assess which of the three meteorological variables most strongly influences EVI anomaly variability.

8.3 Spatial resolution

When combining data from different sources, you need to make sure that the data sets use the same spatial grid. Furthermore, you need to mask out all values that both data sets do not have in common. Finally, the analysis you will perform is computational expensive. Choose a relatively coarse grid so that the analysis does not take too long.   • Detrend precipitation anomalies
# Define a function that removes a linear trend
detrend.fun <- function(x) {
  time <- 1:length(x)
  # If a grid cell contains NA, then set the result to NA
  if (is.na(mean(x))) {
    return(rep(NA, length(time)))
  } else {
    time <- 1:length(x)
    linear.model <- lm(x ~ time)
    detrended.series <- stats::residuals(linear.model)
    return(detrended.series)
  }
}

data.anom.detrend <- app(x = data.anom, fun = detrend.fun)
pr.anom.detrend <- data.anom.detrend

# Have a look at the data

plot(subset(data.anom.detrend, 1:1), col = my.col)

8.5 Causal inference

With the detrended anomalies of the meteorological variables and EVI prepared, you can now assess their statistical associations using Granger causality. This analysis follows a similar approach to the causal inference we previously applied to temperature and albedo in climate model data. Begin by defining a Granger causality function that can be applied to each grid cell.

granger.fun <- function(x) {
  
    # If a grid cell contains NA, then set the result to NA
  if (is.na(mean(x))) {
    return(NA)
  } else {
    
  n <- length(x)
  # Get first (a) and second (b) variable
  a <- x[1:(n/2)]
  b <- x[(n/2+1):n]
  # Convert to time series
  a <- ts(a)
  b <- ts(b)
  tsDat <- ts.union(a, b)
  tsVAR <- vars::VAR(tsDat, p = 2)
  # Apply Granger causality test 
  p.value <- c(vars::causality(tsVAR, cause = "a")$Granger[3]$p.value)
  return(p.value)
  }
}

Check whether precipitation Granger-causes EVI anomalies.

# Stack your raster objects, where the first part is the cause and the second the response
data <- c(pr.anom.detrend, evi.anom.detrend)

# Assess Granger causality
p.value <- app(x = data, fun = granger.fun)

# Create a boolean map where all locations with p-values < 0.01 equal 1 and all remaining gridcells equal zero
p.value[p.value >= 0.05] <- 0
p.value[p.value > 0] <- 1

p.value.pr <- p.value

plot(p.value, col = c("white", "orange"), main = "Precipitation Granger-causes EVI Anomalies")
map("world2", add = TRUE, interior = FALSE)

8.6 Cross correlation

Cross-correlation calculates the correlation coefficients between time series for different time lags. This allows us to identify the time lags at which the correlation between variables is strongest. To begin, we’ll apply this approach to a single grid cell by extracting data for a specific location.

lon <- 131
lat <- -17
coords <- matrix(c(lon, lat), ncol = 2, byrow = TRUE)
location <- vect(coords, type = "points")

plot(p.value)
map("world2", add = TRUE, interior = FALSE)
points(location, col = "red", pch = 16, cex = 1.0)

Extract the values for this location and convert them to a time series.

# Extract data for the location
evi.anom.detrend.gc <- extract(evi.anom.detrend, location)

pr.ts <- ts(pr.anom.detrend.gc)
tas.ts <- ts(tas.anom.detrend.gc)
rsds.ts <- ts(rsds.anom.detrend.gc)

tsDat <- ts.union(evi.ts, pr.ts, tas.ts, rsds.ts)

# Plot time series
plot(tsDat)

Cross correlation gives the correlation coefficients for different time lags. There are positive lags and negative lags:

  • Positive lags: series1 is correlated with past values of series 2
  • Negative lags: series2 is correlated with past values of series 1

The Figure below shows you how the correlation coefficient R changes for different time lags.

We now aim to create two figures: the first shows the time lags with the highest correlation coefficients, and the second displays the corresponding correlation coefficients. For our specific location, the results are as follows for precipitation:

# Compute cross-correlation
ccf_result <- ccf(evi.ts, pr.ts, lag.max = 12, plot = FALSE)

# Find the index of the maximum correlation
max_index <- which.max(ccf_result$acf)

# Extract the maximum correlation and corresponding lag
max_correlation <- ccf_result$acf[max_index]
corresponding_lag <- ccf_result$lag[max_index]

# Combine results for display
result <- data.frame(Max_Correlation = max_correlation, Lag = corresponding_lag)

Now we want to apply this approach to each grid cell. Let’s define a function that finds the time lag with the largest correlation coefficient.

findLag.fun <- function(x) {
  # If a grid cell contains NA, then set the result to NA
  if (is.na(mean(x))) {
    return(NA)
  } else {
    n <- length(x)
    
    # Get first (a) and second (b) variable
    a <- x[1:(n / 2)]
    b <- x[(n / 2 + 1):n]
    
    # Convert to time series
    a <- ts(a)
    b <- ts(b)
    
    # Conduct cross-correlation
    ccf_result <- ccf(a, b, lag.max = 12, plot = FALSE)
    
    # Find the index of the maximum correlation
    max_index <- which.max(abs(ccf_result$acf))
    
    # Extract the maximum correlation and corresponding lag
    max_correlation <- ccf_result$acf[max_index]
    corresponding_lag <- ccf_result$lag[max_index]
    
    # Combine results for display
    result <- corresponding_lag
    return(result)
  }
}
